# 实验报告管理平台

该项目提供一个面向 C 语言课程实验的在线实验报告管理系统，支持以下功能：

- 学生通过学号登录提交 Word (`.docx`) 实验报告。
- 管理员通过 Excel 导入学生名单、创建实验、查看提交情况并导出成绩统计。
- 系统支持调用 OpenAI ChatGPT 接口生成客观成绩与评语（未配置 API Key 时自动回退至关键字评分）。
- 自动将红色字体的成绩与评语添加到 Word 报告首页，并提供下载。

## 快速开始

### 1. 创建并激活虚拟环境（可选）

```bash
python -m venv .venv
source .venv/bin/activate  # Windows 使用 .venv\\Scripts\\activate
```

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 启动开发服务器

```bash
flask --app app:create_app run --debug
```

访问 <http://127.0.0.1:5000> 即可体验系统。首次运行时系统会自动创建默认管理员账号 `admin`/`admin123`。

## 功能说明

### 管理员

- 使用默认管理员账号登录后，可在控制台上传 Excel 学生名单（需包含 `student_number`、`name`、`password` 三列），并在同一页面查看导入结果。
- 管理员可直接在线修改学生姓名、重置密码。
- 可创建 8 次实验（或更多），查看各实验的提交情况，下载带评语的报告。
- 支持导出单次实验的成绩统计为 Excel 文件，并通过“成绩汇总”页面查看所有学生的提交概览与平均分。

### 学生

- 使用学号与初始密码登录后，可查看所有实验并上传 Word 报告。
- 每次提交后系统会自动生成成绩与评语，并在文档首页插入红色字体标注。
- 学生可下载带评语的报告或重新提交覆盖之前的结果。
- 学生可在个人中心修改登录密码，保障账号安全。

## 大模型配置与评分逻辑

- 管理员可在“模型配置”卡片中选择要使用的 ChatGPT 模型（默认 `gpt-4o-mini`）并填写 OpenAI API Key。
- 提交后系统会使用所选模型生成 0~100 分的客观评分及至少 40 字的中文评语，并写入 Word 报告首页。
- 若未配置 API Key 或调用失败，系统会退回到关键字匹配的模拟评分逻辑，确保流程不中断。

评分核心逻辑位于 `app/services.py` 的 `evaluate_report` 函数：它会先尝试调用 ChatGPT，如果失败，则根据“实验目的”“实验原理”等关键词给出基础分和评语。

## 文件存储

- 原始文件存储在 `uploads/` 目录，带评语的文件存储在 `processed/` 目录。
- 目录位置可通过环境变量 `UPLOAD_FOLDER`、`PROCESSED_FOLDER` 配置。
